# KinkDeck 🃏

A quick, playful, swipe-based kink test. Swipe through 20 cards across 10 kinks and get an instant breakdown — no sign-up, no personal questions, nothing stored.

- **Swipe right** — Into it
- **Swipe up** — Curious
- **Swipe left** — Not for me

Also works with the on-screen buttons and arrow keys (↑ / ← / →, Backspace to undo).

## Run it

It's a single self-contained file — no build step, no dependencies. Just open `index.html` in a browser, or serve the folder with any static host (e.g. GitHub Pages).

## Categories

Dominance · Submission · Bondage · Sadism · Masochism · Degradation · Cuckolding · Voyeurism · Exhibitionism · Cross-dressing

Two statements per category; each category is scored 0–100% and shown with a tap-to-expand explainer on the results page.
